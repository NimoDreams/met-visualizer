# Security Policy

## Report A Vulnerability

Please use GitHub's private
[Report a vulnerability](https://github.com/NimoDreams/met-visualizer/security/advisories/new)
form. Do not open a public issue for a suspected vulnerability.

Describe the affected behavior, impact, and reproduction steps without including
RPC credentials, private keys, seed phrases, or sensitive provider responses.
The maintainer will acknowledge the report through the private advisory and
coordinate fixes there.

Security fixes apply to the latest code on `main`; older revisions are not
supported separately.
